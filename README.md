# 💻 .NET Localization

## 📌 About This Repository

This repository contains my learning and practice programs related to **Localization in .NET**.

Localization is the process of adapting an application to support different languages, cultures, and regional settings. It helps applications display content based on the user's language and culture.

## 🎯 Learning Objectives

- Understand Localization and Globalization
- Learn how to support multiple languages
- Display localized text based on user culture
- Work with resource files
- Understand culture-specific formatting

## 🛠️ Technologies Used

- C#
- .NET
- Visual Studio
- Resource Files (.resx)

## 📚 Concepts Covered

- Localization
- Globalization
- CultureInfo
- CurrentCulture
- CurrentUICulture
- Resource Files
- `.resx` Files
- Language Selection
- Culture-Specific Date and Number Formatting
- Multilingual Application Support

## 🌍 Localization Examples

- English language support
- Tamil language support
- Language switching
- Localized messages and labels
- Culture-specific date and currency formatting

## 🌟 Benefits of Localization

- Supports multiple languages
- Improves user experience
- Makes applications accessible to different regions
- Helps create globally usable applications

## 🚀 Purpose

The purpose of this repository is to understand how to develop multilingual applications using .NET Localization concepts.
